# 디자인 가이드 (UI 개발 기준)

모든 UI는 `src/styles/theme.ts` 토큰만 사용합니다. 새 색·크기를 임의로 추가하지 않습니다.

## 기본
- 화면 기준: 1920×1080 (16:9). `<Stage>`가 HD~4K로 스케일합니다. 레이아웃은 px 고정 좌표로 작성합니다.
- 폰트: NEXON Lv2 Gothic (400·700) + JetBrains Mono (숫자·코드·라벨). **font-weight 700 이하.**
- 메인 색: `#f37321` · 성공: 민트 `#3fe0c5` · 경고: `#f2c230` · 오류: `#ff5a6a`
- 배경: 어두운 방사형 그라디언트 + 비네트. 패널은 반투명 `rgba(10,8,6,.6)` + 주황 얇은 테두리.
- 모서리: 사선 컷(`cutCorner`) 10 / 14 / 26px. 둥근 버튼 사용 안 함(키 표시 원형 제외).
- 텍스트 최소화: 안내는 한 줄. 도구 이름만 말하고 클릭 위치는 알려주지 않습니다.

## 화면 흐름
제품 카드 → 세부 조립 카드 → 교육장(HUD)

## 세부 조립 카드 (FIX)
정면 일자 배치 · 선택 카드 가운데·앞 · 양옆 rotateY 바깥 기울기 + 뒤로 + 거리별 투명도(최소 0.3) · 잠금 없음 · 마우스 기울기 효과 없음
카드: 썸네일 · 번호 · DONE/NOW/FINAL · 구간 라벨 · 이름 · 설명 · STEPS/MIN · 진행 바 · "A 교육 시작"

## 교육장 (모든 교육 공통 · 교육마다 다른 건 부품·조립 내용뿐)
| 위치 | 요소 |
|---|---|
| 왼쪽 상단 | 뒤로가기 · 일시정지 |
| 상단 | 제품명 + 구간 진행 바 (구간명 · 단계 n/N · TOTAL %) |
| 상단 중앙 | 단계 태그 + 한 줄 안내 (박스 없음) |
| 중앙 | 확대창(모서리 브래킷) — 창 밖으로 튀어나오지 않음 |
| 확대창 오른쪽 아래 | 도구 거치대 (TOOL REST) |
| 왼쪽 / 오른쪽 | 완성품(진행 구간 점멸) / 재료 구역 |
| 오른쪽 상단 | 미션 목록 (완료·진행 중·대기) |
| 하단 오른쪽 | 시점 초기화(F) · 음성 안내 · 연습/평가 |

공통 흐름: 미리보기(완성/분해/구간) → 교육 시작하기 → 부품 펼침 → 안전 수칙 → 부품 확인(마우스 올리면 즉시 실물 3D) → 진행하기 → 재료 구역 배치 → 실습 → 최종 리포트

V 원형 공구 패널: 3D 도구는 칸 없이 세워 회전 · hover 시 이름·규격 + 아래→위 스캔 · 정답 강조 없음 · 고를 때 오답 표시 없음 · 틀린 도구로 작업하면 "도구가 맞지 않습니다"
